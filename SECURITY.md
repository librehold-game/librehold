# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue or pull request: use **Report a vulnerability** on
the repository's [Security tab](https://github.com/librehold-game/librehold/security/advisories/new), or write to
me@szymonkocur.com. Include what you found, how to reproduce it and what an attacker could do with it.

You will get a reply as soon as possible. Once a fix is released, you will be credited in the release notes unless you
prefer otherwise.

## Supported versions

Only the latest commit on `main` and the server running at librehold.org receive security fixes.
